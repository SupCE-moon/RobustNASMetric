# 20-Model Robust Metric Validation

Date: 2026-07-06

## Setup

- Dataset: CIFAR-10 test subset, reused from local existing copy.
- Model set: 20 RobustBench CIFAR-10 Linf model IDs from `configs/cifar10_linf_20.yaml`.
- Official target: RobustBench CIFAR-10 Linf reported robust accuracy from the RobustBench README model-zoo table.
- White-box run: each model generated its own FGSM adversarial examples on 64 samples.
- Shared-adv run: one shared cache generated by `Standard` with PGD-10 on 128 samples, then reused for all 20 models.
- Spatial Gram implementation: for each selected layer, compute the Gram matrix between normalized spatial feature atoms. Early high-resolution feature maps are adaptively pooled to at most 16x16 spatial positions before the position-position Gram matrix is computed.

## New Files

- `scripts/generate_adv_cache.py`: generate reusable `x, y, x_adv` tensor caches.
- `scripts/fetch_robustbench_scores.py`: fetch RobustBench CIFAR-10 Linf clean/robust accuracy table.
- `scripts/join_robustbench_scores.py`: merge metric CSVs with RobustBench official scores.
- `outputs/adv_cache/cifar10_linf_standard_pgd10_n128_seed20260704.pt`: shared adversarial-example cache.
- `outputs/metrics_20_whitebox_fgsm_n64_spatial_seed20260704.csv`: white-box run with spatial Gram metrics.
- `outputs/metrics_20_shared_standard_pgd10_n128_spatial_seed20260704.csv`: shared-adv run with spatial Gram metrics.
- `outputs/shared_adv_multisource_validation_report.md`: multi-source shared-adv validation using weak, mid-robust, and strong source models.

## Interpretation

The cross-layer second-order-only metric `feature_measure_flow_delta` is weak in both settings. It does not currently justify focusing only on cross-layer feature-flow structure.

The new same-layer spatial second-order metric `feature_measure_spatial_gram_delta` is clearly stronger than `feature_measure_flow_delta`. In the white-box run, its Spearman correlation reaches -0.4541, close to the normalized FSP baseline. In the shared-adv run, it has strong Pearson correlation (-0.9112) but weaker Spearman correlation (-0.2556), suggesting that it captures coarse robustness magnitude but still needs ranking stabilization.

The combined metric `feature_measure_robust_delta` has strong Pearson correlation with official robust accuracy in both white-box and shared-adv settings, which supports the core motivation that adversarial feature-measure displacement is informative. However, its Spearman ranking is unstable. The spatial version `feature_measure_robust_spatial_delta` improves white-box rank correlation (-0.3398) but does not improve shared-adv rank correlation in this single-source setting.

The strict original-style FSP baseline is also weak here. The older normalized `fsp_delta`, logit KL, input gradient norm, and local logit Lipschitz proxies currently rank models better than the proposed combined metric.

## RobustBench / Adversarial Example Database Note

RobustBench is best treated here as a model zoo and standardized evaluation benchmark. It provides public models and evaluation tooling, but not a ready-made downloadable database of pre-generated CIFAR-10 adversarial examples for every attack/model pair. For shared-adv experiments, we should therefore create reproducible caches with explicit metadata: source model, attack, epsilon, steps, sample indices, and seed.

## Multi-Source Shared-Adv Follow-Up

The recommended shared-adv design was executed with three source caches:

1. weak source: `Standard`;
2. mid-robust source: `Engstrom2019Robustness`;
3. strong source: `Wang2023Better_WRN-28-10`.

The three-source averaged result did not automatically improve ranking correlation. The best proposed metric in this follow-up is still the plain spatial Gram displacement:

| metric | Pearson | Spearman | Kendall tau-a |
| --- | ---: | ---: | ---: |
| `feature_measure_spatial_gram_delta` (Ours ablation) | -0.7170 | -0.3564 | -0.2421 |
| `feature_measure_spatial_gram_rel_delta` (Ours ablation) | -0.7528 | -0.1925 | -0.1579 |
| `feature_measure_robust_spatial_delta` (Ours) | -0.8932 | -0.0286 | -0.0105 |
| `fsp_delta` [1,2] | -0.8523 | -0.4135 | -0.2947 |
| `input_grad_l2` [4,7] | -0.9285 | -0.5383 | -0.4316 |
| `local_logit_lipschitz` [5,6] | -0.9310 | -0.2902 | -0.2105 |

The implication is that source averaging reduces single-source attack bias, but the additive first-order-plus-second-order Ours metrics still need calibration. The next useful experiment is therefore not more source models, but coefficient/layer normalization and residual-value testing against strong output/gradient baselines.
