# E30: 计算图结构直接测 op 交互

日期：2026-08-20

## 材料档案

- 类型：指标设计（直接图结构）+ 零成本天花板检验
- 状态：已完成（负结果：直接图结构比特征响应 flow_rel 弱）
- 问题：直接测量「哪个 op 连哪个节点」（op 转移矩阵）能否比 flow_rel（特征响应间接捕捉接线）更好地预测零成本鲁棒性？
- 数据集：现有 CIFAR-10 标签，无下载；纯 CPU 分析
- 搜索空间：NAS-Rob-Bench-201（64 架构）

## 动机

E27/E28 的核心发现是：结构去混杂后唯一存活的信号是「op 交互」（哪个 op 连哪个节点）。flow_rel 通过特征响应间接捕捉这个信号（partial 0.626）。E30 直接测量计算图 DAG 的 op 转移结构，检验能否更直接、更强地捕捉同一信号。

## 方法

NB201 每个 cell 是 4 节点 6 边的 DAG（`edge_sources=[0,0,1,0,1,2]`）。节点间转移为：`e0→e2, e0→e4, e1→e5, e2→e5`。对每个架构，计算：
- **op 转移矩阵**（5×5，25 维）：op 类型 A 连接 op 类型 B 的计数。
- **边位置分布**（6×5，30 维）：哪个 op 在哪个边位置。

然后检验这些图结构特征（在 op 计数之外）能否预测 oracle 鲁棒性。

## 结果

| 分析 | 值 |
|---|---|
| R²(oracle \| op 计数) | 0.815 |
| R²(oracle \| op 计数 + 转移矩阵) | 0.923（**+10.85%**） |
| R²(oracle \| op 计数 + 边位置) | 0.888（+7.3%） |
| 5 折 CV：learned 转移指标 partial | **+0.080**（过拟合崩盘） |
| 手工标量 `chain_score`（conv3x3 链 − pool 链密度）partial | **+0.412** |

## 关键发现

1. **直接图结构在样本内确实解释额外 10.85% 方差**，但这信号在交叉验证下崩到 +0.08——25 个转移特征对 64 个样本严重过拟合。

2. **手工标量（chain_score）partial 只有 +0.412**，低于 flow_rel 的 0.626。说明特征响应（flow_rel）比直接读 op 类型转移更好地捕捉了接线信号——特征携带细粒度接线信息，op 类型转移是粗粒度。

## 结论

直接测计算图 DAG 结构是一条死路：要么过拟合（learned），要么比 flow_rel 弱（手工标量）。零成本 0.63 天花板进一步坐实，且「用特征响应间接捕捉接线」优于「直接读 op 转移」。
