# E35: 最终结论——通用性是多维的，不存在三空间全通的单一指标

日期：2026-09-12

## 研究问题

找到一个**通用**的鲁棒 NAS 指标：能在无需完整对抗训练的前提下预测架构的对抗鲁棒性，且**在多个环境下方向一致**（不能这个环境下行、那个环境下不行）。

## 最终答案

**没有一个指标在三个搜索空间（RB20 / NB201 / DARTS）都强。** 「通用」是一个多维判据，各指标族在不同维度上占优：

- **跨空间零成本**（NB201 + DARTS）：**trnas 族**最强（0.50～0.91），但 RB20 弱（−0.04～−0.14）。
- **跨协议尺度不变**：**gram 族**唯一稳健（0.67～0.84），但 DARTS 弱（e50/e100 接近 0 或负）。
- **结构去混杂非平凡**：**gram 族**（flow_rel/feature_delta）存活（partial 0.62），trnas 崩（partial 0.21）。
- **成熟模型强度**（RB20）：**capacity 族**最强（0.71），但不通用。

不存在「三空间全通 + 去混杂非平凡 + 尺度不变」的全能指标；gram 族与 trnas 族各占一个维度。

## 三族指标的完整定位

| 判据 | gram 族（相对结构） | capacity 族（dispersion 幅度） | loss（绝对输出） |
|---|---|---|---|
| 跨协议一致性（e0，尺度不变） | **稳健 +0.67～0.84** | 中间 +0.45 | **翻转 −0.33** |
| 跨训练稳定性（PGD-7 强对抗） | 稳定 +0.63 | **e5 翻转 −0.45** | 稳定 +0.58 |
| 跨训练稳定性（PGD-1 弱对抗，E34） | 弱 +0.12～0.18 | 稳定 +0.49 | — |
| 成熟模型强度（RB20 adj-Spearman） | 中等 +0.45 | **强 +0.58～0.71** | 强 +0.66 |

**三个方向各占一角，没有指标能同时「通用 + 成熟最强」：**
- **gram 族**：唯一跨协议稳健（尺度不变），但成熟模型中等（RB20 0.45）。
- **capacity 族**：成熟模型强（RB20 0.71），但跨协议中间、且「e5 翻转」是强对抗训练特有的（E34）。
- **loss**：成熟模型最强，但跨协议符号翻转（随机初始化时不可靠）。

## 核心机制：跨协议通用 = 尺度不变性

- **相对结构/方向量**（gram、flow_rel、feature_delta）对「归一化/网络实现」不敏感（跨协议一致性 0.67～0.84）——它们只测形状，不测绝对值，故**跨协议**稳健。
- 注意：尺度不变性只保证「跨协议」稳健，不保证「跨空间」稳健——gram 族在 DARTS 上仍弱（表 4）。跨空间通用是另一个维度，尺度不变 ≠ 跨空间全通。
- **dispersion 幅度量**（capacity）跨协议中间（0.45），且其「e5 翻转」是训练强度依赖的（PGD-7 下翻转、PGD-1 下稳定，E34）——非固有属性，但也不是稳健的通用判据。
- **绝对输出量**（loss/logit）跨协议翻转（−0.33）——随机初始化时符号都不稳，不能作为通用指标。

## 证据链

| 实验 | 结论 |
|---|---|
| E31 | 通用指标是 gram 族（NB201 全阶段 min≥0.63），capacity 在 e5 符号翻转。 |
| E32 | signed capacity 三空间全死（信息在幅度不在符号）；capacity「成熟强但非通用」；DARTS 空间可测但 gram/capacity 失效（trnas 有效 0.75）。 |
| E33 | 通用=尺度不变性；gram 跨协议稳健、loss 跨协议翻转、capacity 中间；给出 bootstrap CI 证明「处处为正/翻转」统计显著。 |
| E34 | capacity 的「e5 翻转」是 PGD-7 强对抗训练特有的（PGD-1 下稳定 +0.49、gram 反而不稳定 +0.18）；修正 E33 的「跨训练稳定性」为训练强度依赖。 |

## 论证

## 最佳指标（按目标）

**核心答案：我们的指标里，最好的是 gram 族 3 个——`fsp_delta`、`feature_measure_struct01_delta`、`feature_measure_moment_delta`。**

| 目标 | 最佳指标 | 关键数据 | 短板 |
|---|---|---|---|
| 通用（尺度不变、处处不差） | gram 族（上述 3 个） | 跨协议 0.67～0.71、NB201 min≥0.63 | DARTS 失效 |
| 零成本去混杂后最能预测 | `feature_measure_flow_rel_delta`、`feature_delta` | partial 0.626 / 0.615 | RB20 弱（0.14～0.21） |
| 成熟模型排序 | `perturbation_capacity_relu_active_delta` | RB20 0.710 | 不通用（e5 翻转） |
| 跨空间零成本最强（含 baseline） | `trnas_r_score`、`trnas_consistency_phi` | NB201 0.90 + DARTS 0.75 | RB20 弱、去混杂崩（op 组成代理） |

**若要推一个「我们的通用指标」，gram 族（fsp_delta / struct01 / moment）是唯一候选；跨空间零成本排序上 trnas（baseline）更强，但它是 op 组成代理（去混杂后崩到 0.21），非真机制。**

## 结论

**「通用」不是单一指标能占满的单一维度。** gram 族（`fsp_delta` / `feature_measure_struct01_delta` / `feature_measure_moment_delta`）是唯一「跨协议尺度不变 + 去混杂非平凡」的候选（代价：DARTS 上弱）；trnas 族是「跨空间零成本最强」的 baseline（代价：RB20 弱、且是 op 组成代理）；capacity 族「成熟最强」但不通用；loss「成熟最强」但跨协议翻转、零成本 DARTS 失效。若论文需一个「尺度不变、去混杂非平凡」的通用指标，gram 族是唯一候选；若需「跨空间零成本排序」，trnas 族更强。
