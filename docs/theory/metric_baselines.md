# Robust Metric Baselines

Source note: these baselines are selected from the user's literature notes in section 2.5.1 of `当前读书笔记与灵感.docx`.

## Current White-Box Protocol

For each model, adversarial examples are generated by that same model:

```text
x_adv = attack(model, x, y)
metric = metric(model, x, x_adv, y)
```

This measures each model's own local stability under a white-box threat model.

## Baseline Metrics Implemented

| Metric | Literature family | Definition proxy | Expected direction |
| --- | --- | --- | --- |
| `input_loss_delta` | input loss landscape / AdvRush / AWP-style flatness | `CE(f(x_adv), y) - CE(f(x), y)` | lower is better |
| `input_grad_l2` | Jacobian / input-gradient regularization | mean per-sample `||d CE(f(x), y) / dx||_2` | lower is better |
| `local_logit_lipschitz` | Lipschitz constant proxy | `||f(x_adv)-f(x)||_2 / ||x_adv-x||_2` | lower is better |
| `margin_input_grad_ratio` | certified lower bound / Jacobian bound proxy | clean logit margin divided by input-gradient norm | higher is better |
| `fsp_delta` | FSP matrix / RobNet-style feature-flow stability | relative Gram/FSP change between clean and adversarial features | lower is better |

## Proposed Metrics Kept For Comparison

| Metric | Role |
| --- | --- |
| `feature_delta` | normalized feature-space perturbation stability |
| `perturbation_capacity_delta` | relative change of centered feature activation capacity |
| `logit_kl` | clean/adversarial output-distribution stability |

## Deferred Experiment

Shared-adversarial metric is intentionally deferred. Later, run:

```text
x_adv_shared = attack(source_model_or_ensemble, x, y)
metric = metric(target_model, x, x_adv_shared, y)
```

This will test whether the metric captures robustness to common external perturbations rather than each model's own white-box perturbation.
