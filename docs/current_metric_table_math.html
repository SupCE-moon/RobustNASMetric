当前 Robust Metric 总表（公式渲染版）

日期：2026-07-03；实验结果为与 adv_acc 的 Spearman 相关系数。

实验设置

  • 数据集：CIFAR10 test split
  • 模型：10 个 RobustBench CIFAR10 / Linf 模型
  • 对抗样本：white-box，每个模型分别生成自己的 \(x_{\mathrm{adv}}\)
  • 攻击：PGD-lite，3 steps
  • 样本数：512
  • All：全部 10 个模型；Robust-only：去掉自然训练的 Standard 模型

符号说明

符号含义
\(x\)clean input
\(x_{\mathrm{adv}}\)adversarial input
\(y\)true label
\(f(x)\)model logits
\(p(x)=\mathrm{softmax}(f(x))\)模型输出概率分布
\(F_l(x)\)第 \(l\) 个中间层特征图
\(\mathrm{GAP}(\cdot)\)global average pooling
\(\mathrm{CE}(f(x),y)\)cross entropy loss
