# 对抗扰动超额特征漂移：新指标设计

状态：**用户已于 2026-10-24 确认设计；尚未预注册、实现或运行正式实验。** 实施前先冻结公式、源码和输入清单，再允许服务器完整运行。此前的 TRNAS/E37 结果用于提出假设，不是这个新指标的独立验证集。

## 1. 研究问题与边界

目标是检验：相对于同一约束下的随机扰动，模型在对抗扰动下额外发生的特征变化，能否成为跨搜索空间的鲁棒性指标，并比现有 E37 多视图指标具有更好的训练阶段稳定性。它不是对 TRNAS 分数或标签拟合的组合，也不预设会超过 TRNAS。

正式主排名沿用冻结的八设置、方向统一 Spearman 与严格准入规则。只有完整、唯一、有限、`status=ok` 的 560 行可参与排名。即使个别模型 OOM、权重缺失或数据不完整，也不得缩小模型集合后给出正式名次。旧 v3、E36、E37 及 TRNAS 严格发布均保持只读；新原始结果存入独立目录。操作范围只限 `wangjiahao` 容器的 `/workspace/robust_metric_lab_nas` 项目，以及指定本地项目。

## 2. 唯一主候选的冻结数学定义

指标名为 `feature_adv_excess_centered_unit_l2`，类别 `Ours / cross_space`，方向 **lower**。每个样本 x 的标签 y 只用于生成冻结协议的 FGSM 对抗样本 x_adv，不用于指标拟合。x_rand 为固定随机符号扰动：每个输入元素在裁剪前取正或负 epsilon，符号由固定种子和全局样本序号生成；同一样本在全部架构、检查点和训练阶段共享相同符号。两种扰动都执行相同的 `[0,1]` 裁剪及 L-infinity 限制，epsilon=8/255。

对现有 E37 的 `all_leaf` 激活记录与 `_anchor_indices(..., max_layers=4)` 选出的固定规则锚层，记层特征 F_l(z) 的形状为 `(C_l,H_l,W_l)`。先对**整个张量**中心化再归一化：

\[
 v_l(z)=\operatorname{vec}(F_l(z)-\operatorname{mean}_{c,h,w}F_l(z)),\qquad
 u_l(z)=\begin{cases}v_l(z)/\|v_l(z)\|_2,&\|v_l(z)\|_2>10^{-12},\\0,&\text{otherwise.}\end{cases}
\]

\[
 d_l(a,b)=\tfrac12\|u_l(a)-u_l(b)\|_2,\qquad
 e_l(x)=d_l(x,x^{adv})-d_l(x,x^{rand}).
\]

每个样本取各锚层 \(e_l\) 的数值中位数；偶数层时取排序后中间两项的算术平均。模型指标为冻结 64 个样本的**样本级结果等权平均**。不使用拟合系数、模型大小、最终鲁棒性标签或阶段信息参与公式。分块计算时累加样本结果再除以固定样本总数，不平均分块均值。

该定义对每层特征的正比例缩放及统一加性平移不变；它**不**保证不同训练阶段的架构排序不变。若锚层特征中心化后为零，按上式处理，不能临时换层、删模型或改变阈值。指标可能为负值，负值不是失败；非有限值才是失败。

固定随机控制是“同一裁剪前 \(L_\infty\) 预算”，不是逐样本裁剪后 \(L_2\) 完全相等。运行时另存对抗与随机扰动的实际 \(L_\infty\)、\(L_2\) 分布；若系统性不匹配，报告为机制解释限制，不事后改随机生成器。还需保存 \(d_{adv}\) 与 \(d_{rand}\) 的样本级诊断汇总，以检查主分数是否仅由随机项驱动；诊断项不是附加正式候选，不进榜。

## 3. 选择这一设计的理由与备选

已完成的严格对照显示：TRNAS Φ/R-Score 在 DARTS e0/e100 的架构排序稳定，而 E37 多视图 max/RMS 在两个阶段排序反转；两者在八设置均值上也未超过 Φ/R-Score。单纯更换 E37 的 `max`、`RMS` 或权重容易根据已有标签过拟合。这里引入模型无关、样本配对的随机基线，提出一个可证伪的机制假设：减去一般扰动响应后，剩余的对抗特异性响应更少受训练阶段总体特征尺度和普通敏感性变化影响。

未采用的路径：①按现有榜单选择 E37 分量和聚合权重，存在明显事后调参风险；②混合 TRNAS 与 E37 分数，可能改善原始名次，却难区分自研指标的独立贡献。当前设计以机制可解释性优先，计算代价预计多一个随机样本的特征前向；实际时间和显存必须实测，不作“低成本”保证。

## 4. 冻结输入与适用范围

严格主网格与旧发布同对象、同样本顺序、同标签：

| 设置 | 对象数 |
|---|---:|
| RB40 mature | 40 |
| NB201 e0/e5/e10/e25/e50 | 每阶段 64，共 320 |
| DARTS e0/e100 | 每阶段 100，共 200 |
| **总计** | **560** |

统一 `sample_offset=0`、`num_samples=64`、`seed=20260808`、FGSM、`epsilon=8/255`，新随机符号主种子冻结为 `20261024`。对全局样本序号 `i=0,…,63`，创建 `numpy.random.Generator(numpy.random.PCG64(20261024+i))`，按该样本输入的 `(C,H,W)` 形状以 C 行主序调用 `integers(0,2,size=(C,H,W),dtype=int8)`，将结果映射为 `2*bit-1`；再转换为输入张量 dtype/device，并用项目原有 `clamp_linf(x+epsilon*sign,x,epsilon)` 得到随机样本。执行清单须另存 NumPy/PyTorch 版本和源码哈希。对同一样本分块大小不同仍须逐位相同。不同模型只可在模型、检查点及按定义产生的 FGSM 方向上不同，随机控制不得因模型而变。

该指标的数学定义和聚合方式在 RB40、NB201、DARTS 完全相同。若任何空间无法保持同一定义，则标记 `space_specific` 或实现失败，不用代理值填充跨空间榜。
