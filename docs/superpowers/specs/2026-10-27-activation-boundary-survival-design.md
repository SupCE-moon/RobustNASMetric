## 1. 研究问题与证据边界

目标是提出一项与 TRNAS Φ 不同的 Ours 指标，并检验它能否在完整 RB40、NB201、DARTS 主网格上超过 Φ，且在独立材料上获得支持。已有严格发布 `strict_adv_excess_release_20261024T110422Z` 中 Φ 排第 1；E37 多视图 max/RMS 分别排第 6/7，对抗超额特征漂移排第 20。DARTS e0/e100 的 E37 九项分数排序均不稳定；逐层诊断只显示探索性关联，不能证明反转原因，也不是本候选的独立验证。

2026-10-27 在唯一允许的 `wangjiahao` 容器内对现有发布做只读复核：发布自检 `PASS`；48,160 个原始键唯一；84 项正式指标各有 560 行，均为 `status=ok`、指标值及目标值有限，八设置数量、精确架构/模型 ID 与三份冻结主网格清单一致，所有正式指标在同一设置的 ID、epoch 和目标值一致。两项空间专属 RACL 仍被排除：其缺值与失败状态保留，不能修改旧原始证据或以此放宽规则。本候选须另立新原始目录；不能覆盖旧 v3、E36、E37 或任一 strict 发布。

## 2. 唯一正式候选及数学定义

暂定注册名 `feature_activation_sign_survival_sum`，归属 `Ours / cross_space`，方向 **higher**。不使用 TRNAS 分数、鲁棒性目标、模型参数量、训练阶段或学习得到的系数来计算分数。

模型固定为 `eval`。对冻结的第 (i) 张输入 (x_i) 及标签 (y_i)，按原主实验 FGSM 协议生成 (x_i^{adv})：(L_\infty) 预算 (8/255)，输入范围裁剪至 `[0,1]`，其余攻击和样本顺序与当前严格主网格一致。标签仅用于生成 FGSM，不进入指标公式。

采集模型中**每次实际调用**的 `torch.nn.Conv2d` 或 `torch.nn.Linear` 模块输出，按前向执行顺序编号 (j=1,\ldots,L)。同一模块重复调用视为不同的 (j)，并用模块路径加调用序号标识；不采集 BN、ReLU、池化、无参数算子或函数式卷积。正常输入与对抗输入必须得到相同的调用标识序列和逐调用张量形状，否则该键失败，不临时删层或替换层。此采集范围在三个空间完全相同。

对每个调用输出展平除 batch 维外的全部 (N_{ij}>0) 个元素，设 (z_{ij,k}) 与 (z^{adv}_{ij,k}) 为同位置的两个数值；严格以 `>0` 判为正，零和负数均判为非正。该调用的状态保持率为

\[
q_{ij}=1-\frac{1}{N_{ij}}\sum_{k=1}^{N_{ij}}\mathbf 1\!\left[(z_{ij,k}>0)\ne(z^{adv}_{ij,k}>0)\right].
\]

样本分数 (S_i=\sum_{j=1}^{L}q_{ij})；模型分数 (S=\frac{1}{64}\sum_{i=1}^{64}S_i)。分块时累加 64 个样本的原始 (S_i)，不得平均分块均值。(L) 是实际调用数，**不除以层数**；这是有意保留、同时必须审计的结构信号。没有 Conv/Linear 调用、空张量、非有限激活/分数、clean/adv 调用或形状不匹配都记失败，不返回代理值。若某层两次均为零，其元素按公式算“保持”，不得事后剔除。

算法不随模型、空间或阶段改变符号阈值、层选择、归一化、方向和样本数。与旧 ReLU-active 指标的激活加权连续特征差值、TRNAS Ψ 的跨图片激活模式数、TRNAS Φ 的权重扰动后特征/参数余弦和均不同；这只是数学定义上的区别，不是优越性的证据。

## 3. 机制假设、风险与预先指定的对照

可证伪假设是：正负状态是否翻转比连续特征距离更少受训练后激活幅度改变影响；对全深度调用求和又保留相对稳定的网络结构信息，因此 DARTS e0/e100 排序可能比 E37 稳定。它可能完全失败：零值过多会虚增保持率，全层求和可能近似只数层数，RB40 的异构模型还可能使结构效应反向。

因此正式分析必须同时报告下列**诊断而非新入榜候选**：每键调用数 (L)、(S/L)、各层翻转率分布、clean/adv 双零比例、运行时和峰值显存；以及仅用 (L) 排序、参数量控制后的相关性、NB201/DARTS 同架构跨阶段秩稳定性。若新分数与 (L) 几乎等价或控制结构后失去信号，只能报告“结构代理”，不能宣称发现独立的抗扰动机制。任何诊断结果都不得用来在本轮改阈值、方向、层集或公式。

未选择的备选：仅按层数/参数量排名，计算简单但缺乏扰动反应；继续调整 E37 的 max/RMS/锚层权重，已有九项 DARTS 阶段反转且事后择优风险高；把 Φ 与 Ours 拟合混合，会使自研贡献及独立性不清楚。本轮只提交上面的一个候选。

## 4. 完整主实验与冻结次序

正式网格固定为 RB40 的 40 个成熟模型、NB201 的 64 架构 × e0/e5/e10/e25/e50 共 320 键、DARTS 的 100 架构 × e0/e100 共 200 键，总计**精确 560 键**。逐键对应当前主网格 manifest 的 ID、epoch、目标、检查点、64 张样本、样本次序、FGSM、seed、epsilon；实施计划须列明每份 manifest 与检查点来源哈希以及新代码/环境哈希，冻结后才允许跑数。设计不得根据任何新候选结果修改。

执行顺序：用户审阅本设计 → 编写并审阅详细实施计划 → 解决隔离工作区依赖及服务器代码/权重一致性 → 失败先行单元测试和不看排名的实现 smoke → 冻结 560 键及源码哈希 → 等待 GPU 达到项目显存门槛 → 在 `wangjiahao` 容器、`/workspace/robust_metric_lab_nas` 内运行完整 560 → 独立严格核验 → 新目录合并并重排名。GPU 不足时监控等待，不影响他人进程。任何缩小模型集合或以局部结果给正式名次均禁止。

## 5. 失败证据、严格判定与多轮选择

每键保存来源、状态、主分数及数值诊断，失败保存原始错误、来源和精确键；原始尝试只追加，不覆盖。唯一有效成功、有限性、协议、代码来源、八设置键集合与冻结清单逐项核验。失败只能在同一公式/协议版本下从精确缺失键续跑；若修复改变数学定义或运行来源，另立版本和发布目录。旧 RACL 等排除项原封保留。

正式主榜采用原有方向统一 Spearman 和八设置等权平均，与 TRNAS Φ 同一冻结网格比较。预定主榜胜出门槛：新指标 560/560 完整合格，平均值大于 Φ，且按同一架构跨阶段联合重抽样的配对差值 95% 区间下界大于零；另报告每设置差值与三空间等权结果，不用有利子集替代主门槛。此开发网格已经参与多轮研究构思，区间是描述性证据，**不是**独立确认性显著性证明；必须列出已试候选及失败，不能把这一轮称作唯一试验。

独立验证分级：RB40 冻结留出 11/11 权重已在一文件替换映射下通过加载检查，但尚未运行任何本候选或 Φ 的完整留出评估。须先冻结替换路径与哈希、11 个键、目标和同一公式，再对 11/11 全部计算并报告配对差值及不确定性；10/11 不可冒充完成。NB201/DARTS 历史候选缺对应旧权重，旧 CSV 也曾参与研究；要支持**三空间外部泛化**，必须在查看本候选留出成绩前，另行冻结不与开发网格重叠且权重、目标协议、来源和全部键可核验的两个空间验证包。重新训练产生的新权重不能与旧模型目标直接拼接。材料未齐时只能陈述已完成的单空间留出范围，不宣布“跨空间独立验证通过”或最终超过 Φ。
