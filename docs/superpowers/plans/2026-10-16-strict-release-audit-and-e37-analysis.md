## 任务 4：核对泛化、机制与计算成本

- [x] 复核 E37 冻结留出集的 99 条原始行、10 个有效模型与 1 个损坏权重的 9 条失败；核对报告中的 20,000 次 bootstrap 设置与区间。点估计已独立从行级值重算，bootstrap 区间尚未独立重复抽样。
- [x] 检查 E37 三分量（中心化通道、空间余弦、跨层对称流）及几何/max/RMS 聚合公式；E37 运行清单记录的八个输入/源码哈希全部匹配当前服务器文件。
- [x] 从行级值复算 E37 max/RMS 的 16 个混杂诊断单元，最大绝对误差低于 `4e-15`；比较逐空间原始相关性与留出方向。未拟合新权重。
- [x] 从 E37 正式运行的首个触发指标提取同模型、同 64 样本、同 CUDA 路径的九指标共享计算耗时，并从各 setting 日志提取峰值显存；保存为独立只读成本审计产物。max/RMS 行自身仅为缓存读取，不当作独立成本。若论文需要阶段级边际成本，再按下述预注册基准补测。

**成本基准预注册草案（尚未运行）：** 固定严格实验的模型权重、每空间至少一个代表模型、同一批 64 个样本、`batch_size=1`、`epsilon=8/255`、相同 GPU 与软件环境。对每个模型先热身 3 次，再重复 10 次；每次重置 E37 缓存并同步 CUDA。分段记录数据准备、扰动/前向与特征提取、三分量构造、max 与 RMS 聚合的耗时，以及整族端到端时间和峰值显存；报告中位数、四分位数和样本数。另测两个聚合从**已有三分量**出发的增量时间，不将缓存命中的逐行 `runtime_sec` 误作独立指标成本。执行前锁定具体模型 ID、GPU 空闲阈值、运行脚本与输出路径；若显存不足，等待而不驱逐其他进程。原始逐次记录和失败日志单独保存，不进入严格主榜。

**验收：** 泛化结论明确区分主网格、留出模型和后验敏感性；成本报告区分共享前向/攻击成本与额外指标聚合成本。
