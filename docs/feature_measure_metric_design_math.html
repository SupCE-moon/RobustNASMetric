Feature Measure ROBUST Metric Design

Date: 2026-07-04 | MathJax rendered formula version

这一版只讨论两个对象：RobNets 论文中的严格 FSP，以及我们的 measure-based ROBUST metric。旧字段 fsp_delta 是 normalized same-layer Gram 变体，不再当作原始 FSP。

1. Strict FSP From RobNets

When NAS Meets Robustness 对第 \(l\) 个 cell 的 FSP 矩阵定义为 cell 输入特征和输出特征的跨层 Gramian：

\[ G_l(x;\theta)= \frac{1}{h w} \sum_{s=1}^{h}\sum_{t=1}^{w} F^{\mathrm{in}}_{l,s,t}(x;\theta) \left(F^{\mathrm{out}}_{l,s,t}(x;\theta)\right)^{\top}. \]

若把同一空间位置的输入/输出特征看成成对原子：

\[ \left(a^{\mathrm{in}}_{l,s}(x),a^{\mathrm{out}}_{l,s}(x)\right) \in \mathbb{R}^{C_{\mathrm{in}}}\times\mathbb{R}^{C_{\mathrm{out}}}, \]

则 FSP 是这个 joint empirical measure 的二阶交叉矩：

\[ G_l(x;\theta)= \int a^{\mathrm{in}}\left(a^{\mathrm{out}}\right)^{\top} \,d\rho_l^x(a^{\mathrm{in}},a^{\mathrm{out}}) = \frac{1}{S_l} \sum_{s=1}^{S_l} a^{\mathrm{in}}_{l,s}(x) \left(a^{\mathrm{out}}_{l,s}(x)\right)^{\top}. \]

论文中的 FSP loss 是：

\[ L^{\mathrm{FSP}}_l = \frac{1}{N} \sum_x \left\|G_l(x;\theta)-G_l(x';\theta)\right\|_F^2. \]
关键修正：原始 FSP loss 没有 \(\|G_l(x;\theta)\|_F+\varepsilon\) 这样的分母。FSP 矩阵内部只有空间平均 \(1/(hw)\)，loss 外部只有样本平均。

RobustBench 模型没有统一的 cell input/output API，因此当前实验用相邻选中 4D activation 近似 cell 输入/输出流：

\[ \widehat{G}_{i,j}(x) = \frac{1}{S} \sum_{s=1}^{S} a_{i,s}(x)a_{j,s}(x)^{\top}, \quad i
\[ \mathrm{fsp\_strict\_delta} = \frac{1}{|\mathcal{P}|} \sum_{(i,j)\in\mathcal{P}} \frac{1}{N}\sum_x \left\| \widehat{G}_{i,j}(x_{\mathrm{adv}}) - \widehat{G}_{i,j}(x) \right\|_F^2. \]

2. First-Order vs Second-Order

第 \(l\) 层 feature map 为：

\[ F_l(x)\in\mathbb{R}^{C_l\times H_l\times W_l}. \]

每个空间位置给出一个局部特征原子：

\[ a_{l,s}(x)=F_l(x)[:,h,w]\in\mathbb{R}^{C_l}. \]

整层 feature map 可以看成 feature space 上的经验测度：

\[ \mu_l^x = \frac{1}{S_l} \sum_{s=1}^{S_l} \delta_{a_{l,s}(x)}. \]

\(\delta_a\) 是位于 \(a\) 点的 Dirac measure，即全部概率质量集中在一个特征向量上。因此 \(\mu_l^x\) 就是这一层所有空间特征向量形成的经验分布。

First-Order

测度的一阶矩是均值：

\[ m_l(x)= \int a\,d\mu_l^x(a) = \frac{1}{S_l}\sum_{s=1}^{S_l}a_{l,s}(x). \]

但只用 \(m_l(x)\) 就退化成 GAP。我们的 first-order 项不用 GAP，而是直接测量局部特征原子的位移：

\[ u_{l,s}(x)= \frac{a_{l,s}(x)}{\|a_{l,s}(x)\|_2+\varepsilon}, \quad w_{l,s}(x)= \frac{\|a_{l,s}(x)\|_2} {\sum_t\|a_{l,t}(x)\|_2+\varepsilon}. \]
\[ D^{(1)}_l(x,x_{\mathrm{adv}}) = \sum_{s=1}^{S_l} w_{l,s}(x) \left\| u_{l,s}(x_{\mathrm{adv}})-u_{l,s}(x) \right\|_2. \]

这里的一阶不是“泰勒一阶”，而是“测度矩的一阶”：它关心单个 feature atom 的直接移动。

Second-Order

二阶矩描述 feature 之间的相互作用。单层形式是：

\[ M_l(x)= \int aa^\top\,d\mu_l^x(a) = \frac{1}{S_l}\sum_s a_{l,s}(x)a_{l,s}(x)^\top. \]

FSP 是跨层二阶矩，它衡量同一空间位置上输入侧特征与输出侧特征如何共同激活：

\[ G_l(x)= \int a^{\mathrm{in}} \left(a^{\mathrm{out}}\right)^\top d\rho_l^x. \]

3. Our ROBUST Metric

我们的 ROBUST metric 保留 FSP 的 feature-flow 二阶结构，同时加入直接的 feature-measure 位移。为了让组合项不被通道数尺度压住，严格 FSP baseline 仍保留论文式平方 Frobenius；但 ROBUST 的二阶项使用每个 FSP 矩阵元素的 RMS 变化：

\[ \widetilde{D}^{(2)}_{i,j}(x,x_{\mathrm{adv}}) = \frac{1}{\sqrt{C_iC_j}} \left\| \widehat{G}_{i,j}(x_{\mathrm{adv}}) - \widehat{G}_{i,j}(x) \right\|_F. \]
\[ D^{(1)}_{i,j} = \frac{1}{2}\left(D^{(1)}_i+D^{(1)}_j\right). \]
\[ D^{\mathrm{ROBUST}}_{i,j} = \widetilde{D}^{(2)}_{i,j} + \lambda D^{(1)}_{i,j}, \quad \lambda=1. \]
\[ \mathrm{feature\_measure\_robust\_delta} = \frac{1}{|\mathcal{P}|} \sum_{(i,j)\in\mathcal{P}} D^{\mathrm{ROBUST}}_{i,j}. \]
