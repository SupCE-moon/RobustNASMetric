# 有符号 vs 绝对 capacity 漂移

- 两个指标只差一个 `abs()`：`perturbation_capacity_delta` 与 `perturbation_capacity_signed_delta`
- 样本：560 个（设置 × 模型/架构），目标是发布表里的鲁棒准确率

## 结论

**不是同一个指标的两种写法（有符号与绝对值是两个不同指标，设计如此）**

- 两者在设置内的秩相关中位数：**+0.017**（最低 -0.758）
- 与 target 的相关**符号相反**的设置：**4 / 8**（nb201_e0、nb201_e25、nb201_e50、darts_e100）
- 有符号指标为负的样本占比（中位数）：+0.484
- 自检：`|带符号| <= 绝对` 不成立的样本数 **0 / 560**（数学上必然为 0；不为 0 说明两个指标不是同一批样本，配对出错）

## 怎么读

- `比值` = 带符号值 / 绝对值。它接近 ±1 表示所有样本朝同一方向变，接近 0 表示上升的样本和下降的样本几乎互相抵消。
- 如果两个指标真是「只差符号」，`ρ(带符号, 绝对)` 应该接近 ±1，且两者与 target 的相关只在符号上不同。表中若出现「相关符号相反」，就说明排序不是简单翻转，而是**换了内容**。
- 这套比较不改变任何已发布数字；它只是说明这两个指标能不能放在一起解读。
- 两个指标**本来就该不同**：一个有符号、一个取绝对值。前者保留「capacity 是升还是降」，后者只问「变了多少」。它们同时出现在榜单上时，名次不能互相印证，必须分别说明。

## 局限

- RB40 只有 40 个模型，单指标 Spearman 的 95% 区间约 ±0.3，该行只能当指示。
- NB201 同一架构有 5 个阶段，样本不独立；这里按设置分别算，没有合并。
- 没有控制模型容量，因此「带符号值与 target 负相关」仍可能是容量混杂。
