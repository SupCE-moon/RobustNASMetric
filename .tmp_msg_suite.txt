feat(audit): run every audit from one command with the wiring in code

Eleven audit scripts now exist, each with different arguments. A handover doc that
lists eleven commands is a handover where someone runs six of them, or passes the
raw rows to the wrong flag and gets a plausible-looking number instead of an error.

`tools/run_audit_suite.py` fixes the argument wiring in code, runs the steps in
dependency order (the redundancy matrix feeds the Phi incremental test), and
writes one pass/fail/skip table. Large inputs that live outside the repository
make a step `skipped`, never `ok`: on a clean clone seven steps cannot run, and a
report that calls that "all checks passed" is worse than no report.

`implementation` and `signed_capacity` exit 1 on purpose (a known gap; a conclusion
that the two metrics differ), so each step declares the exit codes it accepts.

Also fixes self-pollution in `check_doc_links.py`: it only skipped the `doc-links-`
prefix, so the suite's undated `doc-links.md` fed its own 25 missing paths back in
as fresh broken links. Reports are now skipped by prefix set, with a reverse test
that human-written audit reports are still scanned.
